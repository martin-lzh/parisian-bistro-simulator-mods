## English

### Cover artwork

[cover.png](cover.png) is the AI-generated cover used on the [Nexus Mods page](https://www.nexusmods.com/mods/3?game_id=10352), made on 2026-09-26.

### Adding images

Store this Mod's in-game screenshots and promotional artwork here, following the Old Market Simulator Mods folder layout.

| Filename | Content |
| --- | --- |
| `cover.png` | Mod cover for the README or a Mod listing |
| `<scene>-gameplay.png` | In-game screenshot, for example `meal-replacement-gameplay.png` |
| `<scene>-promo.png` | Additional promotional artwork |

- Use PNG, JPG or WebP with lowercase, hyphenated filenames.
- Add an image link only after the file exists. Put the cover under the README title and screenshots next to the matching usage text in both languages.
- For each screenshot, note its date, Mod/game/UE4SS versions, host or guest role and what it shows. Label generated or edited artwork as such.
- Extracted game assets and reverse-engineering material belong in ignored `work/`.

These images are repository documentation and are not included in Mod ZIPs. See the [shared image guidance](../../DEVELOPMENT.md#mod-images) for links that also work from an extracted package. Repository-only README example (paths relative to this Mod's README):

```markdown
![Fresh to Serve cover artwork](assets/cover.png)
![Fresh to Serve in-game screenshot](assets/meal-replacement-gameplay.png)
```

## 中文

### 宣传封面

[cover.png](cover.png) 是 [Nexus Mods 页面](https://www.nexusmods.com/mods/3?game_id=10352)使用的 AI 宣传封面，制作于 2026-09-26。

### 添加图片

此目录存放本 Mod 的实机截图和宣传图，沿用菜市场模拟器 Mods 的目录约定。

| 文件名 | 内容 |
| --- | --- |
| `cover.png` | README 或 Mod 页面使用的宣传封面 |
| `<scene>-gameplay.png` | 实机截图，例如 `meal-replacement-gameplay.png` |
| `<scene>-promo.png` | 其他宣传图 |

- 使用 PNG、JPG 或 WebP，文件名用小写英文和连字符。
- 图片文件加入后再添加引用：封面放在 README 标题下，实机图放在中英文对应的使用说明旁。
- 每张截图记录拍摄日期、Mod／游戏／UE4SS 版本、房主或客机身份及画面内容。生成或编辑过的宣传图应注明。
- 提取的游戏资源和反编译资料放在被忽略的 `work/`。

图片仅用于仓库文档，不进入 Mod ZIP。解压后的说明如何引用图片，见[公共图片说明](../../DEVELOPMENT.md#mod-图片)。仅在仓库中使用的 README 示例（路径相对于本 Mod 的 README）：

```markdown
![焕鲜上桌宣传封面](assets/cover.png)
![焕鲜上桌实机截图](assets/meal-replacement-gameplay.png)
```
