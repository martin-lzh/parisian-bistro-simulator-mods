### Adding images

| Filename | Content |
| --- | --- |
| `cover.png` | Mod cover for the README or a Mod listing |
| `<scene>-gameplay.png` | In-game screenshot, for example `counter-checkout-gameplay.png` |
| `<scene>-promo.png` | Additional promotional artwork |

- Use PNG, JPG or WebP with lowercase, hyphenated filenames.
- Add an image embed only after the file exists. Put the cover below the README title and gameplay images next to the matching usage text, in both languages.
- For each new screenshot, note its date, Mod/game versions and host or guest role here. Label AI-generated or edited artwork as such.
- Extracted game assets belong in the ignored `work/` folder, not here.

These images stay out of the Mod ZIP. For links that also work from an extracted package, see the [shared image guidance](../../DEVELOPMENT.md#mod-images). Repository-only README example (paths relative to this Mod's README):

```markdown
![Auto Checkout cover artwork](assets/cover.png)
![Auto Checkout in-game test](assets/counter-checkout-gameplay.png)
```

### 添加图片

| 文件名 | 内容 |
| --- | --- |
| `cover.png` | README 或 Mod 页面使用的宣传封面 |
| `<scene>-gameplay.png` | 实机截图，例如 `counter-checkout-gameplay.png` |

- 使用 PNG、JPG 或 WebP，文件名用小写英文和连字符。
- 图片文件加入后再添加引用：封面放在 README 标题下，实机图放在中英文对应的使用说明旁。
