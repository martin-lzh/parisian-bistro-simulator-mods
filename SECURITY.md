# Security / 安全反馈

[English](#english) · [中文](#中文)

## English

Report vulnerabilities in the original Mod code, package handling or repository automation, such as unintended file access or credential exposure. Ordinary installation and gameplay problems belong in [Support](SUPPORT.md#english). Current source versions receive priority; fixes for every historical version are not promised.

Use an existing private contact with the maintainer. No dedicated security email is published. If you have no private contact, open an [issue](https://github.com/martin-lzh/parisian-bistro-simulator-mods/issues) asking only for a private reporting channel, without exploit details or confidential information. If the repository's Security page offers private vulnerability reporting, that is also suitable; this document does not assert that the feature is enabled.

Once a private channel is available, provide the affected version, impact, minimal reproduction and any proposed mitigation. Redact private data and do not send credentials, game binaries, saves or extracted material. Test only in an environment you are authorized to use. Coordinate disclosure with the maintainer; there is no fixed response or resolution deadline. Published fixes should identify affected versions and any update requirements in the Mod's CHANGELOG.

## 中文

安全反馈适用于原创 Mod、安装包处理及仓库自动化中的漏洞，例如非预期文件访问或凭据泄露。一般安装和游戏问题请看[帮助](SUPPORT.md#中文)。优先处理当前源码版本，不承诺维护所有历史版本。

请使用与维护者已有的私下联系方式，目前未公布专用安全邮箱。没有私下联系方式时，可以提交 [Issue](https://github.com/martin-lzh/parisian-bistro-simulator-mods/issues)，仅请求提供私密报告渠道，不包含利用细节或保密信息。如果仓库 Security 页面提供私密漏洞报告入口，也可使用；本文不代表已开启该功能。

确认私密渠道后，提供受影响版本、影响范围、最小复现和可能的缓解方式。先脱敏，不发送凭据、游戏文件、存档或提取资料，仅在获准使用的环境验证。公开细节前与维护者协调，不承诺固定回复或修复时限。已发布修复应在 Mod 的 CHANGELOG 中说明受影响版本及升级要求。
